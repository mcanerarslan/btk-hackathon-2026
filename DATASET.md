# DriveWise Vehicle Dataset

This project uses a demo vehicle catalog for route-aware car rental recommendations.

The dataset includes:

- Vehicle name and segment
- Daily rental price
- Fuel type and transmission
- Fuel consumption
- Luggage capacity
- Seat count
- Comfort and performance scores
- Route suitability tags
- Short catalog notes

Dataset contribution: [yarenyz](https://github.com/yarenyz)
